# Интеллектуальная система управления освещением

Исследовательский веб-прототип для мониторинга и адаптивного управления городской системой освещения на основе IoT и ESP32-S3.

## Назначение

Система предназначена для сравнения двух режимов управления:

- традиционный режим «таймер / фотореле»;
- адаптивный IoT-режим на базе ESP32-S3.

Прототип собирает измерения, отображает их в реальном времени, сохраняет результаты в SQLite и рассчитывает потенциальную экономию энергии.

## Возможности

- мониторинг напряжения, тока, мощности и освещённости;
- включение и выключение освещения через браузер;
- переключение обычного и адаптивного режимов;
- передача телеметрии и команд через MQTT;
- виртуальная модель ESP32-S3 без физического оборудования;
- контроль состояния связи ESP32-S3;
- предупреждения о потере связи, перегрузке и отклонении напряжения;
- график мощности и журнал событий;
- сравнение средней мощности двух режимов;
- сохранение измерений в базе SQLite;
- экспорт исследовательских данных в CSV;
- готовая прошивка для ESP32-S3.

## Архитектура

В Docker запускаются три сервиса:

1. `research-web-app` — Flask-приложение и веб-интерфейс.
2. `research-mqtt` — MQTT-брокер Eclipse Mosquitto.
3. `research-sensor` — виртуальная модель ESP32-S3.

Основные MQTT-темы:

| Тема | Назначение |
|---|---|
| `lighting/sensor/data` | Телеметрия устройства |
| `lighting/control/light` | Команда включения или выключения |
| `lighting/control/mode` | Выбор режима управления |
| `lighting/device/status` | Состояние подключения устройства |

## Режимы управления

### Таймер / фотореле

Виртуальная модель поддерживает ток приблизительно `3,0–3,4 А`, пока освещение включено.

### Адаптивный IoT

Мощность изменяется в зависимости от освещённости:

| Освещённость | Диапазон тока модели |
|---|---|
| менее 30 лк | 2,4–2,6 А |
| 30–50 лк | 2,0–2,3 А |
| более 50 лк | 1,7–1,9 А |

Эти диапазоны являются модельными и не заменяют реальные измерения.

## Эксперименты

Для предварительной проверки можно выполнить:

1. сравнение средней мощности обычного и адаптивного режимов;
2. анализ зависимости мощности от освещённости;
3. измерение времени обнаружения потери связи;
4. проверку успешности команд включения и выключения;
5. длительный тест стабильности и полноты телеметрии;
6. экспорт данных и анализ в Excel.

Расчёт экономии:

```text
Экономия, % = (Eобычный − EIoT) / Eобычный × 100
```

Результаты виртуальной модели подходят для проверки программного обеспечения и методики. Для научного вывода об экономии необходимы реальные сопоставимые ночные измерения.

## Прошивка ESP32-S3

Файл прошивки:

```text
firmware/esp32_s3_lighting/esp32_s3_lighting.ino
```

Перед загрузкой в реальную плату необходимо указать:

```cpp
const char* WIFI_NAME = "имя сети Wi-Fi";
const char* WIFI_PASSWORD = "пароль Wi-Fi";
const char* MQTT_SERVER = "IPv4-адрес компьютера с Docker";
```

В Arduino IDE выберите:

```text
ESP32S3 Dev Module
```

В текущей прошивке `USE_REAL_SENSORS = false`, поэтому формируются тестовые показания. После приобретения оборудования необходимо подключить реальные датчики и установить `USE_REAL_SENSORS = true`.

## Безопасность

Текущая конфигурация Mosquitto с анонимным доступом предназначена только для локального лабораторного прототипа. Для эксплуатации необходимы аутентификация, шифрование TLS и ограничение сетевого доступа.

Не подключайте ESP32-S3 или макетную плату напрямую к сети 220 В. Силовую часть должен проектировать и подключать квалифицированный специалист с использованием гальванической развязки и защитной аппаратуры.
